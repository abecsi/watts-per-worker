# Watts per Worker

What would it take, in electricity, machines, land and materials, to give every knowledge worker an AI co-worker? An interactive scenario model built from published per-task energy measurements, IEA outlooks, campus land use and data-center material intensities.

This is a scenario model, not a forecast. Every figure is sourced in the page's appendix.
